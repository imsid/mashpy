# Mash

This repo is mashpy, the Mash library. The SDK reference for building on Mash
(specs, tools, providers, hosts, workflows, policies, sessions, Cortex) is
[`docs/sdk-reference.md`](docs/sdk-reference.md); read it when a task touches
the public authoring surface. Each module documents itself in
`src/mash/<module>/README.md`, and `src/mash/<module>/AGENTS.md` holds the
rules that must stay true in that module.
